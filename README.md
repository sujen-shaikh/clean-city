# CleanCity

A smart civic reporting platform for reporting garbage and civic issues with photo, GPS, and status tracking.

## Run locally

1. Install dependencies:
   - `npm install`
   - `cd client && npm install`
   - `cd server && npm install`
2. Start both apps:
   - `npm run dev`
3. Open the client at http://localhost:5173 and the server at http://localhost:5000.
